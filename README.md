# 💱 Currency Converter

A simple, responsive currency converter built with HTML, CSS, and JavaScript.

**Live Demo:** https://maryamshuaibumusa706-netizen.github.io/currency-converter/

### Features
- Convert between NGN, USD, EUR, GBP
- Swap currencies with one click
- Live conversion as you type
- Input validation for invalid amounts

### Tech Used
- HTML, CSS, JavaScript
- Conversion logic using a base currency (USD)

### What I Learned
- Handling user input and validation
- DOM events (click, input, change)
- Formatting numbers for display
